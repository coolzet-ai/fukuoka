## GitHub Pages 배포 방법
1. GitHub에서 **Public** 또는 **Private** 저장소를 만들고 파일을 동일한 폴더 구조로 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
3. **Branch: main / Folder: /(root)**를 선택하고 저장합니다.
4. Pages의 안내 주소(예: `https://USER.github.io/REPOSITORY/`)를 휴대전화에서 엽니다.
5. 스마트폰 브라우저의 **홈 화면에 추가**를 누르면 앱처럼 실행할 수 있습니다.

파일을 바꿨는데 이전 화면이 보이면 브라우저 새로고침/사이트 데이터 초기화를 하세요. `sw.js`의 `CACHE` 버전을 올려 변경 배포를 빠르게 반영할 수 있습니다.

## 2026.11.24 — 일정 및 날씨 UI 개편

- **도시별 날씨:** 날짜·도시·날씨 아이콘·최고/최저기온·강수확률을 한 줄로 표시합니다. 모바일 너비가 좁으면 해당 줄만 가로 스크롤합니다. 날씨는 Open-Meteo API로 갱신되며, 통신이 없으면 확인 당시 예보를 임시 표시합니다.

- **접근성:** 큰 글씨·고대비 모드와 모바일 하단 메뉴를 유지했습니다. 접기·완료 버튼은 키보드로 사용할 수 있고 ARIA 상태를 제공합니다.

## 2026.11.24 — 경로 지도와 모바일 화면 최적화

- 매일 오른쪽에 **동선지도**를 추가했습니다. 온라인에서는 OpenStreetMap 지도를 이용해 주요 장소의 순서를 번호 핀과 점선으로 표시합니다. 지도와 핀은 개략적이며 실제 도로 주행 경로가 아닙니다. **실제 차량 길찾기** 버튼으로 Google 지도 내비게이션을 여세요.
- 외부 지도 스크립트 또는 지도 타일을 불러올 수 없는 상황을 위해 정적 SVG 동선도도 기본 제공합니다. OpenStreetMap 지도에는 저작자 표시를 유지했습니다.
- 특히 귀국일 토요타 렌터카 **정확한 반납 영업소는 예약서 확인 전이므로 지도에 특정 위치를 만들지 않았습니다.** 호텔·후쿠오카공항 위치를 표시하고, 반납점은 예약서 확인 후 경로를 조정하세요.
- 모바일에서 **가로 스크롤 방지**: 날씨는 공간에 맞는 한 줄 요약, 날짜 버튼은 2열 그리드, 동선 태그는 여러 줄로 자연스럽게 배열, 호텔 이름은 한 줄 말줄임(정식 명칭은 제목/접근성 정보) 처리했습니다. 여행 전체를 읽기 위한 세로 스크롤은 유지합니다.
- 상단 배너 높이, 제목·문단 줄간격, 카드 사이 여백을 조금 줄였습니다. 어르신용 큰 글씨·고대비 기능과 주요 버튼 크기는 유지합니다.
- 오프라인 캐시에 참조돼 있던 사용하지 않는 hero.webp 경로를 실제 hero.svg로 수정했습니다.
