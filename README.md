## 파일 구성
- `index.html` : 메인 페이지
- `styles.css` : 반응형·큰 글씨·고대비 디자인
- `app.js` : 날짜별 일정, 지도 링크, 경비 자동계산, 체크리스트, 사진 기록
- `assets/kyushu-hero.svg` : 벡터 여행 분위기 그림(실제 관광지 사진 아님)
- `manifest.webmanifest`, `sw.js` : 홈 화면 설치·한 번 방문 후 일부 오프라인 열람 지원

## GitHub Pages 배포 방법
1. GitHub에서 **Public** 또는 **Private** 저장소를 만들고 파일을 동일한 폴더 구조로 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
3. **Branch: main / Folder: /(root)**를 선택하고 저장합니다.
4. Pages의 안내 주소(예: `https://USER.github.io/REPOSITORY/`)를 휴대전화에서 엽니다.
5. 스마트폰 브라우저의 **홈 화면에 추가**를 누르면 앱처럼 실행할 수 있습니다.

파일을 바꿨는데 이전 화면이 보이면 브라우저 새로고침/사이트 데이터 초기화를 하세요. `sw.js`의 `CACHE` 버전을 올려 변경 배포를 빠르게 반영할 수 있습니다.

## 2026.11.24 — 일정 및 날씨 UI 개편

- **도시별 날씨:** 날짜·도시·날씨 아이콘·최고/최저기온·강수확률을 한 줄로 표시합니다. 모바일 너비가 좁으면 해당 줄만 가로 스크롤합니다. 날씨는 Open-Meteo API로 갱신되며, 통신이 없으면 확인 당시 예보를 임시 표시합니다.
- **호텔 이름:** 카드에는 한 줄로 읽기 쉬운 짧은 표시명을 사용합니다. 정확한 공식 호텔명은 접근성용 제목 정보로 유지합니다.
- **일정표:** 기존 시간순 동선을 유지하며, 관광·쇼핑(청록색)과 식사·카페(금색)를 구별합니다. 날짜별 오른쪽에는 주요 스팟 사진과 출처, 해당 날짜 예보, 관광·식사 요약을 따로 둡니다.
- **여행 완료:** 날짜별 ‘✓ 이날 여행 완료’를 누르면 해당 날짜의 상세 일정만 자동으로 접힙니다. ‘＋ 일정 다시 펼치기’로 열 수 있으며, ‘완료 취소’도 가능합니다. 체크 상태는 브라우저 로컬 저장소에 저장됩니다.
- **사진 사용:** 원 출처의 관광 이미지 8장을 외부 링크로 표시하고 출처를 표기합니다. 외부 사이트에서 직접 이미지 표시를 막거나 오프라인일 경우 사진 출처 링크를 안내합니다. 실제 여행 사진 기록은 사용자의 기기에만 보관됩니다.
- **접근성:** 큰 글씨·고대비 모드와 모바일 하단 메뉴를 유지했습니다. 접기·완료 버튼은 키보드로 사용할 수 있고 ARIA 상태를 제공합니다.
